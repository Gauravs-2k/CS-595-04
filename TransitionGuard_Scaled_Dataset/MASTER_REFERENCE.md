# TransitionGuard Scaled Synthetic Dataset Master Reference Guide

## Overview
This scaled dataset is designed to rigorously test and validate the **TransitionGuard** clinical gap detection system. It now contains 5 distinct patient archetypes, each with 5 unique patient variants, totaling 25 comprehensive records. Each record includes a longitudinal history, a discharge summary with deliberately injected documentation gaps of varying severities, and a ground truth JSON file for automated scoring.

## Dataset Structure
The dataset is organized by patient archetype and then by variant:

- `TransitionGuard_Scaled_Dataset/`
  - `P1/` (Cardio-Metabolic-Renal)
    - `V1/` (Clean)
      - `patient_history.md`
      - `discharge_summary.md`
      - `ground_truth.json`
    - `V2/` (Moderate)
      - ...
    - `V3/` (Severe)
      - ...
    - `V4/` (Moderate)
      - ...
    - `V5/` (Severe)
      - ...
  - `P2/` (Respiratory-Infectious)
    - `V1/` (Clean)
      - ...
    - ...
  - ... (for P3, P4, P5)

Each variant folder contains:
1. `patient_history.md`: The longitudinal medical record (Problem List, Meds, Allergies, Labs, Visit Notes).
2. `discharge_summary.md`: The hospital discharge summary with injected discrepancies.
3. `ground_truth.json`: Structured list of all injected gaps for evaluation.

## How to Use This Dataset
1. **Ingestion**: Load the `patient_history.md` as the system's "baseline" knowledge for the patient.
2. **Analysis**: Process the `discharge_summary.md` through the TransitionGuard extraction and comparison agents.
3. **Evaluation**: Compare the system's output against the `ground_truth.json`.
4. **Scoring**: Calculate Precision and Recall based on how many ground truth gaps were correctly identified.

## Discrepancy Taxonomy
The gaps are categorized into five types:
- **Medication**: Omissions, dose changes, allergy conflicts, drug-drug interactions.
- **Diagnosis**: Missing active conditions or unaddressed new findings.
- **Follow-up**: Missing specialty or PCP appointments.
- **Lab**: Unaddressed abnormal values or pending results.
- **Instruction**: Missing clinical guidance (e.g., activity restrictions, wound care).
